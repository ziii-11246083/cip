## 11-2 預期評審提問與建議回答

### Q1: 你們跟 TradingView / CoinMarketCap 有什麼不一樣？

**建議回答**：
- TradingView 是圖表工具，CMC 是數據目錄；我們是**風險評估平台**
- 我們不做 K 線圖、不做技術指標競爭；而是回答「我現在該注意什麼風險？」
- 核心差異化：SFI 風險指標（Copula 尾部相關分析）、AI 對話式建議、詐騙檢測自動化、Podcast 雙聲線播報

### Q2: AI 教練說「交給 GPT」——你們的 AI 價值在哪裡？

**建議回答**：
- 不是裸呼叫 GPT，而是**注入 Domain Knowledge**：
  - SFI 風險評分公式（Copula + Beta + Lambda）
  - 即時幣價 tool calling
  - 幣種元數據（共識機制、板塊分類、風險等級）
  - 系統提示工程（500+ tokens 的結構化投資規則）
- 做過 prompt engineering：限制 GPT 不推薦具體買賣點、不報明牌、強調風險
- 對比測試：同樣問題問 ChatGPT vs Smart Invest，Smart Invest 能引用即時價格與風險數據

### Q3: SFI 風險指標是怎麼算的？有理論基礎嗎？

**建議回答**：
- SFI（Smart Invest Fragility Index）基於 **Copula 尾部相關性**：
  1. 對 BTC 報酬率做 Copula 擬合（Clayton/Gumbel）
  2. 計算尾部相關參數（lambda_lower）
  3. 結合 Beta 係數（對 BTC 的敏感度）
  4. 正規化為 0–100 分數
- 參考文獻：Patton (2006) Copula Modeling、Christoffersen (2012) 尾部風險
- 分級：≥65 danger / 40–64 warning / <40 safe
- 詳見 `docs/12-AI風險控管與回測方法.md` §12-3

### Q4: 詐騙檢測怎麼運作？準確率多少？

**建議回答**：
- 三層防護：
  1. GMGN 合約安全掃描（Honeypot/Mint/Tax 檢測）
  2. 網域註冊資訊檢查（WHOIS + SSL 證書）
  3. 社群訊號交叉驗證（PTT 討論 + RSS 新聞情緒）
- 誠實說：目前尚無大規模標記資料集做準確率驗證，但每層都有**白名單/黑名單規則**
- 可檢測 scam 類型：Honeypot、Rug Pull 高風險合約、釣魚域名、假交易所

### Q5: 模擬交易有做回測嗎？結果如何？

**建議回答**：
- 目前 MVP 的模擬交易是**即時模擬**（real-time paper trading），而非歷史回測
- 已設計回測框架（滾動視窗法、Sharpe/MDD 指標），詳見回測方法文件
- 策略分三種風險等級（保守/穩健/積極），參數可調整
- 交易記錄保存在 Supabase + 本地 JSON，可匯出分析
- 未來 Phase 2 將串接歷史資料做完整回測

### Q6: 你們的資料從哪裡來？會準嗎？

**建議回答**：
- 即時價格：CoinGecko API（free tier，30 calls/min）
- 歷史資料：yfinance（Yahoo Finance）
- 社群情緒：PTT 爬蟲（DigiCurrency 板）+ RSS（CoinDesk、CoinTelegraph）
- 合約安全：GMGN API
- 所有外部資料都有 error handling 與 fallback（若 API 失敗，顯示快取資料或友善提示）
- 資料清洗：去重、時間窗過濾、HTML 標籤清除、非中文/英文內容過濾

### Q7: 你們的系統安全嗎？使用者資料怎麼保護？

**建議回答**：
- 身份驗證：Supabase Auth（JWT + RLS）
- 資料隔離：所有查詢以 `user_id` 過濾，使用 Supabase Row Level Security
- API 保護：`@token_required` 裝飾器驗證 Bearer token
- 敏感資訊：`.env` 管理 API keys，`.gitignore` 排除 `serviceAccountKey.json`
- HTTPS：Render 部署自動啟用 TLS
- 密碼不落地：Supabase 託管密碼 hash，後端不儲存明碼

### Q8: 你們的商業模式能賺錢嗎？

**建議回答**：
- 三層訂閱制：Free / Pro ($9.99) / Premium ($24.99)
- MVP 月成本 $21–$136，10 位 Pro 會員即可 cover
- 規模化後約需 60 位 Pro 會員達損益兩平
- 目標市場：台灣 50 萬+ 加密貨幣投資者，初期轉換率 2–5% 即有 1,000–2,500 位付費用戶潛力
- 詳見 `docs/05-商業模式與競品分析.md`

### Q9: 為什麼選 Flask 而不是 FastAPI / Django？

**建議回答**：
- Flask 輕量、學習曲線低，適合 MVP 快速迭代
- 專題時間有限，團隊熟悉 Python + Flask 生態
- Supabase 分擔了大部分後端邏輯（Auth、DB、RPC），Flask 主要做路由與 API 編排
- 未來若需高併發，可遷移至 FastAPI（路由簽章相似，遷移成本可控）

### Q10: 你覺得這個專案最大的限制是什麼？

**建議回答**：
- 最大限制是**資料來源的依賴性**：CoinGecko free API 有 rate limit，PTT 爬蟲不穩定
- 其次是**AI 輸出的非確定性**：GPT 回應可能每次不同，我們用 prompt engineering + temperature 控制來降低變異
- 第三是**尚無真實使用者回饋**：MVP 功能完整但未上線營運，缺乏使用者行為數據來迭代
- 這些在文件中都有明確標示為 MVP 限制，並規劃了未來改進方案

## 11-5 注意事項

1. **不要過度承諾**：明確區分「已實現」與「規劃中」
2. **誠實面對限制**：評審欣賞誠實揭露限制並規劃改進的態度
3. **準備好 live demo**：確保本地環境可正常啟動、API key 已設定
4. **熟悉程式碼**：評審可能要求看特定功能的 source code
5. **聚焦核心價值**：AI + 風險評估，不是交易工具
