# 第 5 章 商業模式與競品分析

> 查詢與重算基準：2026-08-20。幣別均為 USD、未含可能適用的稅。官方價格會變動，上線前需重新查核。本文將「目前 runtime」、「內部估算」與「未實作方案」分開，不把預估寫成營運成果。

## 5-1 產品定位

Smart Invest Crypto 是以「投資前風險理解」為核心的加密資產教育與決策輔助平台，主要面向需要繁體中文說明的新手與中階使用者。產品不保管資金、不執行真實交易，也不承諾報酬。

現階段可驗證的差異化不是「市面唯一」，而是把以下能力放在同一個風險流程中：

- 市場與 SFI 風險指標。
- 可疑投資文案的規則、RAG 與 LLM 分層證據。
- 帶 trace、citation、feedback 與固定資料集 regression gate 的 RAG 回答。
- 模擬交易與獨立的假設式壓力測試。
- Ethereum Mainnet 公開地址唯讀同步 MVP；與模擬帳本分離，尚未部署正式 migration。

### 5-2-2 可重算的單次 AI 成本假設

Base case 將一次文字回答建模為：

- GPT-5.4：2,000 input + 800 output tokens。
- Query rewrite：500 input + 100 output tokens（用 GPT-4o mini）。
- Embedding：500 tokens（用 text-embedding-3-small）。

公式：

```text
每次回答成本
= 2,000/1,000,000 × 2.50
+   800/1,000,000 × 15.00
+   500/1,000,000 × 0.15
+   100/1,000,000 × 0.60
+   500/1,000,000 × 0.02
= US$0.017145
```

這不是帳單平均值。正式上線必須用 trace 的 `prompt_tokens`、`completion_tokens`、endpoint 與 model 實測分布替換假設；TTS 因尚無 audio-token/min 實測，以下以獨立月預算池表示，不硬換算分鐘。

## 5-3 收益模式與損益平衡

### 5-3-1 方案是定價假設，不是已上線商品

| 方案 | 規劃月費 | 可驗證現況 |
|---|---:|---|
| Free | US$0 | 公開頁與 Demo 體驗存在；沒有正式 usage entitlement |
| Pro | US$9.99 | **planned**：無 checkout、webhook、subscription CRUD 或限額服務 |
| Premium | US$24.99 | **planned**：公開錢包 Beta flag 不等於付費資格 |

任何「每日 20 次」、「無限使用」或「歷史回測」都不能當成已交付賣點，除非後續真的實作 server-side entitlement、usage counter、付款與退款流程。

### 5-3-2 Base case 單位經濟

以 Stripe 公開標準費率作**暫代假設**、退款／稅務準備 3%，且 Pro/Premium 分別每月 100/300 次文字回答：

| 方案 | 月費 | 金流費假設 | 3% 準備 | 文字 AI | 單位貢獻（未含 TTS／固定／人力） |
|---|---:|---:|---:|---:|---:|
| Pro | 9.99 | 0.59 | 0.30 | 1.71 | **7.39** |
| Premium | 24.99 | 1.02 | 0.75 | 5.14 | **18.07** |

損益平衡公式：

```text
需要付費會員數 = ceil((固定服務成本 + TTS 預算) / 加權平均單位貢獻)
```

在 80% Pro / 20% Premium mix 下，加權平均單位貢獻約 US$9.52：

| 每月固定服務 + TTS 預算 | 損益平衡付費會員 |
|---:|---:|
| US$25 | 3 |
| US$102（Base：77 + 25） | 11 |
| US$326（Scale allowance：226 + 100） | 35 |
| US$500 | 53 |

這只證明數學可重算，不證明轉換率、留存、願付價格或市場規模。原先「6–12 個月必然損平」與「台灣 50 萬使用者」沒有本次可驗證來源，已移除；需以訪談、landing-page conversion 與實際 cohort data 驗證。

## 5-4 競品比較

> 查詢日均為 2026-08-20。價格可能因地區、稅、促銷與年繳而不同；比較的是使用者工作，不宣稱功能一對一或「市面唯一」。

| 產品 | 主要對象／核心工作 | 官方價格證據 | 與 Smart Invest 的重疊 | 可驗證差異與缺口 |
|---|---|---|---|---|
| TradingView | 需要專業圖表、指標、alert、社群腳本的交易者 | Free；Essential US$12.95/月、Plus US$29.95、Premium US$59.95（頁面顯示年繳特價）；[官方 pricing](https://www.tradingview.com/pricing/) | 市場觀察、技術分析 | Smart Invest 不應比拚圖表深度；可主打繁中風險解釋、組合健檢與 RAG 證據，但目前 alert/歷史回測更弱 |
| CoinStats | 多錢包／交易所資產聚合、P&L、提醒與分析 | Basic free；Premium 頁面顯示 US$13.99/月 after trial；[官方 pricing](https://coinstats.app/pricing/) | Portfolio、唯讀同步、風險資訊 | CoinStats 支援更多 portfolios、transactions、wallets/exchanges；Smart Invest 目前只做 Ethereum 公開地址 Beta，差異在教育型風險流程而非同步廣度 |
| Koinly | 交易匯入、對帳與加密稅務報告使用者 | Free；Newbie US$49、Hodler US$99、Trader from US$199 / tax year；[官方 pricing](https://koinly.io/pricing/) | exchange/wallet sync、portfolio tracking | Koinly 強在稅務、成本基礎與對帳；Smart Invest 沒有稅務功能，只能在投資前風險與解釋性上區隔 |
| CoinGecko | 市場資料瀏覽者與需要 API 的開發者 | API Demo US$0；Basic US$35/月（月繳）；[官方 API pricing](https://www.coingecko.com/en/api/pricing) | 幣價、市值、metadata | Smart Invest 依賴 CoinGecko，而不是其資料規模競爭者；價值必須來自風險計算、RAG 與個人化流程 |
| 泛用 AI 助理 | 需要一般問答、寫作與推理的使用者 | 本表不做不同產品方案價格混比 | 投資問題問答 | Smart Invest 的可驗證加值是實際工具資料、受控 prompt、trace/citation/eval；若沒有即時資料或 citation，就不能聲稱一定優於泛用 AI |

### 5-4-1 目前最合理的差異化敘事

1. 「風險先行」：不鼓勵下單，先顯示集中、FOMO、可疑文案與情境風險。
2. 「回答可追溯」：trace 只記實際注入來源，feedback 與離線 regression 分開；feedback 不等於 ground truth。
3. 「繁體中文教學流程」：將技術資料轉成容易理解的風險說明。
4. 「資料邊界透明」：公開錢包、模擬帳本、壓力測試與規劃中的交易所同步不混用。

上述是定位假設，仍需用目標使用者訪談、任務完成率、留存與願付價格驗證。

## 5-5 MVP 與 roadmap

| 模組 | 2026-08-20 狀態 | 商業上可說的話 |
|---|---|---|
| 市場、單幣分析 | implemented / external-data dependent | 可展示市場與風險資訊；不可保證資料永不延遲 |
| AI Chat / Agent / Podcast / Health | implemented 或 partial，依 `docs/18` | 有 RAG trace/citation/fallback；不可說答案已達某準確率 |
| RAG 評測 | local runner + baseline/regression contract implemented | 可重跑 retrieval metrics；15 題仍 pending human review，沒有 approved baseline |
| 可疑文案辨識 | deterministic rules + local RAG + LLM | 只分析文字，不是合約、網域或鏈上掃描 |
| 模擬交易 | partial；Supabase DDL/RPC 不在 repo，Demo 有 local fallback | 是紙上交易，不是真實下單 |
| 情境壓力測試 | implemented，純合成 snapshot | 可比較四種固定假設；不是歷史回測或價格預測 |
| Ethereum 公開錢包唯讀同步 | code/migration ready、未部署 | Beta MVP；只支援單鏈 fungible assets，不是交易所自動同步 |
| 訂閱／金流／用量限制 | planned | 只能談商業假設，不能展示為完成流程 |

下一步商業優先順序：

1. 先用 10–20 位目標使用者驗證「風險解釋 + 資產同步 + AI citation」是否提高信任與回訪。
2. 再用 server-side entitlement 與 usage telemetry 驗證 Pro/Premium 差異；尚未確認願付價格前，不先做完整金流。
3. 只有在 test Supabase 完成 RLS/RPC migration integration、provider 成本可觀測後，才開放真實資產 Beta。
4. 人工審核 15 題 RAG dataset 並核准 clean baseline，才能開始對外談品質趨勢。

## 5-6 免責與決策原則

平台內容僅供教育與參考，不構成投資建議、交易推薦、稅務或財務顧問服務。過去績效不代表未來；AI、外部資料與合成情境都可能錯誤、延遲或遺漏。使用者應自行查證並諮詢合格專業人士。

全站 footer 已包含免責文字；真正上線收費前仍需另做台灣消費者保護、電子商務、稅務、退款、隱私與金融廣告合規審查。
