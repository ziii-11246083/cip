# 第 5 章 商業模式與競品分析

## 5-1 產品定位

Smart Invest Crypto 是一個**以 AI 輔助風險評估為核心**的加密貨幣投資決策平台，目標使用者為：

- 剛進入加密貨幣市場的新手投資者
- 希望有系統化風險評估工具的中階投資者
- 需要快速掌握市場情緒與敘事方向的資訊需求者

不同於純交易工具，Smart Invest 聚焦在**「幫助使用者避免犯錯」**：追高檢測、詐騙辨識、過度集中風險提醒、AI 教練引導。

## 5-3 收益模式設計

### 5-3-1 三層定價策略

| 方案 | 月費 (USD) | 核心功能 |
|------|-----------|---------|
| **免費版 (Free)** | $0 | 市場總覽、單幣分析、社群情緒、敘事雷達、詐騙檢測、Podcast（每月限 5 次 AI 生成） |
| **進階版 (Pro)** | $9.99/mo | 含免費版全部 + AI 投資教練（每日 20 次）、健康度檢查（每月 30 次）、模擬交易（3 組策略）、無廣告 |
| **專業版 (Premium)** | $24.99/mo | 含 Pro 全部 + AI 教練無限制、Podcast 無限制、模擬交易無限制（10 組策略）、AI Agent 自動交易建議、優先客服、歷史回測 |

### 5-3-2 損益兩平點計算

- MVP 階段：3–10 位 Pro 會員即可 cover 基礎成本
- 規模化階段：約 60 位 Pro 會員 或 25 位 Premium 會員即可損益兩平
- 以台灣市場初估：若每月吸引 200–500 位活躍用戶、轉換率 5–10%，**6–12 個月內可達損益平衡**

### 5-3-3 API 成本管控策略

1. **Prompt 壓縮**：系統提示控制在 500 tokens 內，使用 GPT-4o-mini 處理常規對話
2. **快取 (Caching)**：市場資料 5 分鐘快取、RSS 30 分鐘快取
3. **Token 限額**：免費版每日 AI token 上限 5K、Pro 版 50K、Premium 無限制
4. **串流 (Streaming)**：使用 Chat Completion streaming 降低感知延遲

## 5-4 競品分析

### 5-4-1 直接競爭者

| 平台 | 核心功能 | 定價 | Smart Invest 差異化 |
|------|---------|------|-------------------|
| **TradingView** | 技術圖表、社群腳本、篩選器 | Free / Pro $12.95/mo / Premium $49.95/mo | 不做圖表競爭；聚焦 AI 風險評估、中文內容、詐騙檢測 |
| **CoinGlass** | 清算熱力圖、資金費率、OI 數據 | Free / Pro | 不做衍生品數據競爭；聚焦個人化 AI 建議與初學者教育 |
| **CoinMarketCap** | 市值排名、基本資訊、Portfolio 追蹤 | Free | 補其缺乏的：AI 對話式建議、風險健康度評分、詐騙檢測 |
| **Messari** | 專業研究報告、鏈上數據 | Pro $24.99/mo+ | 不走專業研究員市場；面向一般投資者、中文優先 |

### 5-4-2 間接競爭者

| 平台 | 重疊功能 | Smart Invest 策略 |
|------|---------|------------------|
| **ChatGPT / Claude** | 可回答投資問題 | 我們內建即時幣價、市場情緒、SFI 風險指標等 Domain Knowledge |
| **YouTube 財經頻道** | 市場分析內容 | Podcast 可自訂主題、雙人對話式、隨選即聽 |
| **幣圈 Telegram/Discord 群** | 資訊交流 | 提供結構化資料而非零散訊息；詐騙檢測自動化 |
| **Binance/交易所內建工具** | 基本圖表、模擬交易 | 平台中立、不導流特定交易所、風險提醒優先而非鼓勵交易 |

### 5-4-3 競爭優勢總結

1. **AI + Domain Knowledge**：不是泛用型 GPT，而是注入 SFI 風險公式、幣種元數據、即時市場資料的垂直 AI
2. **中文優先**：完整繁體中文介面與內容，瞄準台灣/香港市場缺口
3. **風險導向**：大多數競品鼓勵交易，我們優先提醒風險（追高檢測、過度集中、詐騙掃描）
4. **Podcast 差異化**：雙聲線對話式市場播報，市面上尚無直接競品
5. **開放 MVP**：免費版即可使用多數核心功能，降低獲客門檻

### 5-5-3 目前 MVP 限制（透明揭露）

| 限制 | 說明 | 未來方案 |
|------|------|---------|
| 無交易所自動同步 | 模擬交易需手動操作，無法自動匯入真實交易所持倉 | Phase 2 串接交易所 API |
| 幣種上限 24 個 | 市場頁面限 CoinGecko 前 24 大（可透過環境變數調整） | 改用 Pro API 或分頁載入 |
| PTT 爬蟲穩定性 | 受 PTT 防爬機制影響，可能偶爾失敗 | 增加備援資料源 |
| 回測功能未完整 | 策略回測只有框架，尚無完整歷史回測報告 | Phase 2 補回測引擎 |
| AI 輸出非確定性 | GPT 模型每次輸出可能有差異 | 以結構化輸出 + prompt 固定化降低變異 |
