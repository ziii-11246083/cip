# 第 9 章 Markdown 轉圖片說明

本章說明如何將本專案 `docs/` 內的 Markdown 文件轉換成圖片檔案

## 9-1 準備環境

1. 安裝 Python 套件：

```bash
pip install -r requirements.txt
```

2. 確認已安裝系統套件，WeasyPrint 需要以下常見依賴：

- `libpangocairo-1.0-0`
- `libgdk-pixbuf2.0-0`
- `libcairo2`

在 Ubuntu 上可以執行：

```bash
sudo apt update
sudo apt install -y libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libcairo2 libffi-dev libjpeg-dev libpango1.0-dev libgdk-pixbuf2.0-dev libxml2 libxml2-dev libxslt1-dev
```

> 如果你使用的是其他 Linux 發行版，請使用對應的套件管理器安裝

## 9-2 轉換腳本

已建立腳本：`scripts/markdown_to_image.py`

用法：

```bash
python scripts/markdown_to_image.py docs/06-設計模型.md output/06-設計模型.png
python scripts/markdown_to_image.py docs/07-實作模型.md output/07-實作模型.png
python scripts/markdown_to_image.py docs/08-資料庫設計.md output/08-資料庫設計.png
```

範例：

```bash
mkdir -p output
python scripts/markdown_to_image.py docs/07-實作模型.md output/07-實作模型.png
```

## 9-3 進階使用

如果你想把多個檔案一次轉檔，可以在 shell 裡運行：

```bash
mkdir -p output
for md in docs/*.md; do
  name=$(basename "$md" .md)
  python scripts/markdown_to_image.py "$md" "output/${name}.png"
done
```

## 9-4 注意事項

- 目前腳本將 Markdown 轉成 HTML 再由 WeasyPrint 產生 PNG
- 若內容太長，請分段轉檔，或先轉成 PDF 再另行裁切
- Mermaid 圖表在本腳本中不會自動渲染成 SVG；若需要完整圖表，建議先用專門工具產生圖檔再放入文件
