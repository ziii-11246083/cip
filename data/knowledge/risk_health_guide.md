# 健康度檢查指標解讀指南

## 集中度指標

### Top1 佔比
- 單一最大持倉佔總資產的比例
- < 15%：健康，分散良好
- 15–30%：中度集中，需注意該幣種風險
- > 30%：過度集中，強烈建議降低該幣種佔比

### Top3 佔比
- 前三大持倉合計佔總資產的比例
- < 40%：健康
- 40–60%：中度集中
- > 60%：過度集中，建議重新分配

## 波動率指標

### 年化波動率
- 根據歷史價格計算的價格波動程度（年化）
- < 50%：低波動（如 BTC、ETH）
- 50–100%：中度波動（如 SOL、AVAX）
- > 100%：高波動（大部分山寨幣、Meme 幣）
- 保守型投資者應控制組合波動率在 60% 以下

## 回撤指標

### 最大回撤 (Maximum Drawdown)
- 歷史最高點到最低點的最大跌幅
- < 20%：相對穩定
- 20–40%：中等風險
- > 40%：高風險，需有較強心理準備

## 風險等級綜合判斷

### 保守型配置建議
- BTC + ETH >= 70%
- 單一幣種 <= 10%
- 穩定幣 >= 30%
- 目標年化波動 < 50%
- 最大回撤警戒線：10%

### 穩健型配置建議
- BTC + ETH >= 50%
- 單一幣種 <= 20%
- 穩定幣 >= 15%
- 目標年化波動 < 80%
- 最大回撤警戒線：20%

### 積極型配置建議
- BTC + ETH >= 30%
- 單一幣種 <= 35%
- 穩定幣 >= 5%
- 目標年化波動 < 120%
- 最大回撤警戒線：35%

## 報告解讀建議
- 先看集中度（Top1/Top3）→ 過度集中是最大風險來源
- 再看波動率 → 決定是否能承受日常價格波動
- 最後看最大回撤 → 極端情況下的潛在損失
- 三項指標有一項超標就應該調整配置
